- **References on the Rust host work as they did on the Python host.**
  - A reference standing alone as a paragraph (`{{d:notes/Roof/body}}`, or a workbook cell's
    `{{t:...}}`) writes the value's own Markdown (its list items, its emphasis) as blocks.
  - A call that wrote values by reference lists them in `data.facts` where its tool says none
    itself, `replace_text` among them.
  - A source's refusal of the one value a `from` names keeps its `details`
    (`{"code": "no_key_column"}`).
